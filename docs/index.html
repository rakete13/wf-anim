WF Anim · v1.4.0 · GSAP 3.13

Ein Attribut,
eine Animation.

Standard-Animationen für jedes Webflow-Projekt. Element auswählen, unter Custom Attributes data-anim mit einem Wert aus dieser Liste setzen, fertig. Jede Zeile unten zeigt die Animation live; ein Klick auf das Attribut kopiert es. Was beim Laden schon im Bild ist, bleibt ruhig. Die Überschrift hier oben animiert trotzdem, weil sie data-anim-intro trägt.

Dein System hat „Bewegung reduzieren“ aktiviert. Die Library zeigt Inhalte dann bewusst ohne Animation an, genau wie bei deinen Besuchern mit dieser Einstellung.
↳ Einbinden

In drei Schritten ins Projekt

Einmal im Template-Projekt einrichten, danach steckt alles in jeder Kopie. Im Webflow Designer selbst läuft Custom Code nicht, dort bleiben alle Elemente sichtbar und bearbeitbar.

Head Code

Verhindert, dass beim Laden etwas aufblitzt: Er versteckt Intro-Elemente und zugeklappte Akkordeon-Inhalte und zeigt den Preloader, bevor die Seite zum ersten Mal gezeichnet wird. Lädt die Library nicht innerhalb von drei Sekunden, wird alles wieder normal angezeigt.

<!-- WF Anim · Head Code -->
<script>
document.documentElement.classList.add('js-anim');
try{if(sessionStorage.getItem('wfa-preloaded'))document.documentElement.classList.add('wfa-preloaded')}catch(e){}
setTimeout(function(){if(!window.WFAnim)document.documentElement.classList.remove('js-anim')},3000);
</script>
<style>
.js-anim [data-anim-intro]:not([data-anim-intro="false"]) { opacity: 0; }
.js-anim:not(.wfa-preloaded) [data-anim="preloader"] { display: flex !important; }
.js-anim [data-accordion-content] { height: 0; overflow: hidden; }
[data-anim="split-chars"] { font-kerning: none; }
</style>

GSAP aktivieren

Im Projekt unter Settings → GSAP integration GSAP einschalten und die Plugins ScrollTrigger, SplitText, ScrambleText und DrawSVG anhaken. Webflow liefert GSAP dann selbst aus, du brauchst keinen externen Server.

Footer Code

Entweder eine Zeile, die die Library aus GitHub lädt. Bequem für eigene und betreute Projekte; die IP-Adresse der Besucher geht dabei an jsDelivr.

<script src="https://cdn.jsdelivr.net/gh/rakete13/wf-anim@1.4.0/src/wf-anim.min.js"></script>

Oder eingebettet: den Inhalt von webflow/footer-code.html aus dem Repo einfügen. Dann hängt das Projekt an keinem fremden Server, ideal bei Übergabe an Kunden.

Startbildschirm und Intro

Elemente, die beim Laden schon im sichtbaren Bereich (oder darüber) liegen, bleiben ruhig und sind sofort da: gut für Ladezeit, Screenreader und ohne Aufblitzen. Animiert wird, was beim Scrollen neu ins Bild kommt. Soll ein Element im Startbildschirm trotzdem animieren, z. B. die Hero-Headline, bekommt es zusätzlich data-anim-intro.

Projekt-Defaults (optional)

Setzt den Hausstil eines Projekts. Muss im Footer Code über dem Library-Code stehen. Alles, was du nicht angibst, behält den Standardwert.

<script>
  window.WFAnimConfig = {
    duration: 0.9,          // Sekunden
    ease: 'power3.out',
    start: 'top 85%',       // wann Reveals starten
    distance: '2.5rem',     // Weg bei fade-up & Co.
    stagger: 0.08,
    locale: 'de-DE',        // Zahlenformat für counter
    mobileBreakpoint: 768,  // für data-anim-mobile="false"
    staticOnLoad: true      // false = auch im Startbildschirm animieren
  };
</script>

Basis-Reveals

Elemente erscheinen, sobald sie in den sichtbaren Bereich scrollen. Standardmäßig einmalig; mit data-anim-repeat auch erneut.

Fade

Einblenden mit Bewegung aus der jeweiligen Richtung. fade-left bewegt sich nach links, kommt also von rechts.

  • fade-in · fade-up · fade-down · fade-left · fade-right
  • data-anim-distance="3rem" Weg (px, rem, vh, vw)
fade-up
fade-left

Scale & Blur

Leicht aus kleiner Größe oder aus der Unschärfe. Wirkt ruhiger als ein Fade mit Weg.

  • data-anim-scale="0.85" Startgröße (Standard 0.92)
  • data-anim="blur-in" · data-anim-blur="20" in px
scale-in
blur-in

Clip

Aufdecken über eine Maske. Ideal für Bilder und farbige Flächen. Die Richtung gibt an, wohin sich die Kante bewegt.

  • clip-up · clip-down · clip-left · clip-right

Curtain

Eine Farbfläche wischt über das Bild und gibt es frei, das Bild zoomt dabei leicht heraus. Attribut an den Wrapper des Bildes.

  • data-anim-color="#ff5a1f" Farbe der Fläche, auch Variablen
  • data-anim-direction="left" · up · down (Standard right)
2

Gruppen & Listen

Das Attribut kommt an den Container, die Kinder erscheinen nacheinander. Bei Collection Lists das Attribut an die Collection List setzen, nicht an den Wrapper.

Stagger

Direkte Kinder erscheinen versetzt. Liegen die Elemente tiefer verschachtelt, markiere sie mit data-anim-item.

  • data-anim-stagger="0.12" Abstand in s
  • data-anim-stagger-type="scale-in" jeder Reveal-Typ

Grid-Stagger

Breitet sich im Raster aus, standardmäßig von der Mitte. Gut für Logo-Wände und Galerien.

  • data-anim-from="start" · center · end · edges · random
  • data-anim-stagger-type wie bei stagger

Text

Basiert auf GSAP SplitText. Zeilen werden nach Resize und Font-Laden automatisch neu berechnet. Für Screenreader bleibt der Text lesbar.

Split Lines

Zeilen gleiten nacheinander aus einer Maske. Der Klassiker für Headlines.

  • auch split-words (Wort für Wort)

Gute Animation fällt nicht auf. Sie lenkt den Blick dorthin, wo er hin soll.

Split Chars

Buchstabe für Buchstabe. Am besten für kurze Headlines bis etwa vier Wörter.

Scramble

Der Text entschlüsselt sich. Nur für reinen Text ohne verschachtelte Formatierung.

  • data-anim-chars="01" eigene Zeichen, oder upperCase, lowerCase

Highlight

Ein Marker oder eine Unterstreichung zeichnet sich ein. Ans Inline-Element (Span) im Text hängen.

  • data-anim-style="underline" · data-anim-thickness="0.15em"
  • data-anim-color="#ffd400" oder CSS-Variable --anim-highlight

Wir bauen Websites, die schnell laden und sich gut anfühlen.

Rotate Words

Ein Wort in der Headline wechselt in Schleife. In Webflow das Wort in einen Span setzen, dort steht das erste Wort; die übrigen kommen ins Attribut. Läuft auch im Startbildschirm.

  • data-anim-words="Marken, Shops" weitere Wörter, mit Komma getrennt
  • data-anim-interval="3" Sekunden pro Wort

Wir bauen Websites, die bleiben.

Typewriter

Text tippt sich Zeichen für Zeichen. Der Platz ist von Anfang an reserviert, das Layout springt nicht. Nur für reinen Text ohne Formatierung.

  • data-anim-speed="20" Zeichen pro Sekunde (Standard 30)
  • data-anim-cursor="false" ohne Schreibmarke

Hallo. Diese Zeile schreibt sich gerade selbst.

4

Scroll-gebunden

Diese Animationen folgen direkt der Scrollposition und laufen beim Hochscrollen rückwärts.

Bild-Parallax

An den Image-Wrapper (festes Seitenverhältnis). Das Bild darin ist höher als der Wrapper; die Library misst den Überstand und bewegt das Bild genau um diesen Wert.

  • Bild in Webflow: width 100% · height 110% · object-fit: cover
  • data-anim-amount="15" setzt die Bildhöhe auf 115 %
  • data-anim-direction="up" Richtung umkehren

Element-Parallax

Ein beliebiges Element bewegt sich langsamer oder schneller als die Seite. Negative Werte machen es schneller.

  • data-anim-speed="0.3" (Standard 0.2)
0.25
−0.15

Image Zoom

Das Bild im Wrapper zoomt beim Scrollen langsam heraus.

  • data-anim-scale="1.3" Startzoom (Standard 1.2)

Text Fill

Der Text färbt sich Wort für Wort ein, während du scrollst. Für große Statements.

  • data-anim-opacity="0.2" Startdeckkraft
  • data-anim-start / data-anim-end Scrollbereich

Wir glauben, dass jede Bewegung auf einer Website einen Grund braucht. Alles andere ist Lärm.

Progress Bar

Zeigt den Scrollfortschritt. Die Leiste oben auf dieser Seite ist eine. Styling (fixed, Höhe, Farbe) machst du in Webflow.

  • data-anim-trigger="#artikel" nur Fortschritt eines Bereichs

Image Expand

Das Bild wächst beim Scrollen von einer kleineren Fläche auf die volle Breite. Der Wrapper ist im Layout voll breit, eine Maske (clip-path) schneidet ihn anfangs zu. Nichts im Grid verschiebt sich.

  • data-anim-radius="24px" Ecken im kleinen Zustand
  • data-anim-zoom="false" ohne Bild-Zoom
  • data-anim-pin Section bleibt stehen, bis das Bild voll ist

Scrollytelling

Links Textabschnitte, rechts ein stehendes Bild, das zum jeweils aktiven Abschnitt wechselt. Attribut an den Container. Die Abschnitte bekommen data-scrolly-step, die Bilder data-scrolly-media und liegen gemeinsam in einem Wrapper. Die Library lässt diesen Wrapper festkleben und die Bilder übereinander liegen.

  • data-anim-dim="1" inaktive Abschnitte nicht abdunkeln (Standard 0.35)

  • Kein overflow: hidden auf dem Container oder darüber

Video im Bild

Hover

Eigenes Attribut data-hover an die Card oder den Button. Der Hover über das ganze Element löst den Effekt aus, das Ziel darin findet die Library selbst. Mehrere Effekte trennst du mit Leerzeichen.

So ist es aufgebaut

Bei Bild-Effekten sucht die Library das erste Bild in der Card. Soll ein anderes Element reagieren, bekommt es data-hover-target, bei mehreren Effekten mit dem Namen als Wert, z. B. data-hover-target="arrow".

  • Läuft mit Maus und bei Tastatur-Fokus (Tab)
  • Auf Touch-Geräten aus, dort bleibt alles wie gestaltet

  ├── img-wrapper
  │     └── img    ← wird skaliert (automatisch)

        ├── title

Seite & Navigation

Effekte für die ganze Seite: Header, Hintergrund, Scrollverhalten und Cursor.

Preloader

Overlay beim ersten Laden, mit Zähler und Balken, danach gleitet es weg. Intro-Animationen (data-anim-intro) starten erst, wenn der Preloader verschwindet. In Webflow das Element auf Display none stellen; der Head Code zeigt es während des Ladens. Zum Gestalten im Designer kurz auf Flex stellen.

  • Kinder: data-preloader-counter (0–100) und data-preloader-bar
  • data-anim-once="session" nur einmal pro Besuch
  • data-anim-duration="2" Mindestdauer in Sekunden
  • data-anim-exit="fade" · slide-down (Standard slide-up)

Nav Hide

Der Header verschwindet beim Runterscrollen und kommt beim Hochscrollen zurück. Der Header dieser Seite nutzt es. Zusätzlich bekommt er ab dem Offset die Klasse is-scrolled, die du in Webflow als Combo-Klasse gestalten kannst (z. B. Schatten).

  • An die Navbar; in Webflow auf Position fixed oder sticky stellen
  • data-anim-offset="200px" erst ab dieser Scrolltiefe
  • Bleibt sichtbar bei Tastatur-Fokus und geöffnetem Mobile-Menü

Background Color

Solange die Section die Bildschirmmitte abdeckt, wechselt der Seitenhintergrund fließend auf ihre Farbe. Die Section selbst braucht in Webflow einen transparenten Hintergrund. Die Farben stehen außerdem als Variablen --anim-bg und --anim-text bereit.

  • data-anim-color="#141824" Hintergrund, auch Variablen
  • data-anim-text-color="#ffffff" Textfarbe
  • data-anim-target=".page-wrapper" anderes Element statt body

Smooth Scroll

Weiches, leicht nachlaufendes Scrollen mit dem Mausrad. Tastatur, Scrollbalken und Touch bleiben normal. Wird global eingeschaltet, nicht per Element. Probier es mit dem Schalter im Header dieser Seite.

  • Am body, oder im Footer vor der Library: WFAnimConfig = { smoothScroll: true }
  • Wert 0.06 = weicher, 0.2 = direkter (Standard 0.1)
  • data-anim-native-scroll an Bereichen, die selbst scrollen sollen
  • Bei „Bewegung reduzieren“ automatisch aus

Cursor

Eigener Cursor, den du in Webflow gestaltest: ein Element irgendwo auf der Seite (z. B. in einem globalen Component) mit Position fixed und Deckkraft 0. Über Links wird er größer, über Elementen mit data-cursor="Text" zeigt er den Text im Kind mit data-cursor-label. Auf dieser Seite aktiv.

  • Klassen is-hover und is-text als Combo-Klassen gestalten
  • data-anim-scale="2" Größe über Links (Standard 3)
  • data-anim-lag="0.3" Nachlauf in Sekunden
  • data-anim-hide-native System-Cursor ausblenden
  • Auf Touch-Geräten automatisch aus

Infrastruktur

Was die Library im Hintergrund erledigt, und wie du sie bei Bedarf steuerst.

  • Bewegung reduzieren: Ist die Systemeinstellung aktiv, werden Inhalte ohne Animation angezeigt. Ausnahmen sind Progress Bar, Horizontal Scroll, Nav Hide (ohne Gleiten) und Background Color, weil sie für die Bedienung gebraucht werden oder keine Bewegung sind. Smooth Scroll und der eigene Cursor sind dann aus.
  • Barrierefreiheit: Noch nicht eingeblendete Elemente sind nur durchsichtig, nicht versteckt. Screenreader lesen sie vor, die Browser-Suche findet sie. Bekommt ein Link darin per Tastatur den Fokus, erscheint das Element sofort. Counter und Scramble geben Screenreadern immer den fertigen Text.
  • Fehlertoleranz: Fehlt ein Plugin oder ist ein Wert unbekannt, erscheint eine Warnung in der Konsole und das Element wird normal angezeigt.
  • Hover: läuft nur mit Maus oder Trackpad und bei Tastatur-Fokus. Bei „Bewegung reduzieren“ bleiben nur Farbeffekte (img-darken, fill, underline, reveal ohne Bewegung). Webflow-Dropdowns nutzen selbst ein data-hover-Attribut, dort bitte keinen Effekt setzen.
  • Nicht mischen: Kein data-anim auf Elementen, die zusätzlich eine native Webflow Interaction haben. Beide setzen transform und überschreiben sich.
  • Debug-Modus: Zeigt farbige Start- und Endmarken jeder Scroll-Animation, eine Übersicht in der Konsole und typische Einrichtungsfehler (z. B. Bild beim Parallax nicht höher als der Wrapper, Section mit eigenem Hintergrund bei bg-color, zusätzliche Webflow Interaction am selben Element). Einschalten mit ?wfanim-debug am Ende der Seitenadresse, mit data-anim-debug am body (alle) oder an einem einzelnen Element (nur dieses). Vor dem Livegang wieder entfernen. Auf dieser Seite meldet er Image Expand und Shrink, weil die Demos in der Textspalte liegen statt in voller Breite – genau dafür ist die Prüfung da.
  • Lazy Loading: Die Library rechnet nach dem Laden der Schriften und nach dem Auf- und Zuklappen eines Akkordeons neu. Verändert sich das Layout anders (Tabs, eigene Skripte), rufe WFAnim.refresh() auf.
WFAnim.init(element)   // neue Elemente animieren, z. B. nach CMS Load More
WFAnim.refresh()       // Positionen neu berechnen
WFAnim.destroy()       // alles zurücksetzen
WFAnim.smoothScroll(true)  // Smooth Scroll per Code an (false = aus)
WFAnim.register('mein-effekt', (el, opts) => {
  gsap.from(el, { rotate: -8, autoAlpha: 0, scrollTrigger: { trigger: el, start: opts.start } });
});
