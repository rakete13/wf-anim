WF Anim · v1.0.0 · GSAP 3.13

Ein Attribut,
eine Animation.

Standard-Animationen für jedes Webflow-Projekt. Element auswählen, unter Custom Attributes data-anim mit einem Wert aus dieser Liste setzen, fertig. Jede Zeile unten zeigt die Animation live; ein Klick auf das Attribut kopiert es.

Dein System hat „Bewegung reduzieren“ aktiviert. Die Library zeigt Inhalte dann bewusst ohne Animation an, genau wie bei deinen Besuchern mit dieser Einstellung.
↳ Einbinden

In drei Schritten ins Projekt

Einmal im Template-Projekt einrichten, danach steckt alles in jeder Kopie. Im Webflow Designer selbst läuft Custom Code nicht, dort bleiben alle Elemente sichtbar und bearbeitbar.

Head Code

Versteckt animierte Elemente, bevor sie zum ersten Mal gezeichnet werden. Lädt die Library nicht innerhalb von drei Sekunden, wird alles wieder sichtbar.

<script>
  document.documentElement.classList.add('js-anim');
  setTimeout(function () {
    if (!window.WFAnim) document.documentElement.classList.remove('js-anim');
  }, 3000);
</script>

  .js-anim [data-anim="grid-stagger"], .js-anim [data-anim="scramble"], .js-anim [data-anim="text-fill"],
  .js-anim [data-anim="counter"], .js-anim [data-anim="draw-svg"], .js-anim [data-anim="progress-bar"],
  .js-anim [data-anim="pin"] [data-anim-item] { visibility: hidden; }
  [data-anim="split-chars"] { font-kerning: none; }
</style>

GSAP aktivieren

Im Projekt unter Settings → GSAP integration GSAP einschalten und die Plugins ScrollTrigger, SplitText, ScrambleText und DrawSVG anhaken. Webflow liefert GSAP dann selbst aus, du brauchst keinen externen Server.

Footer Code

Den kompletten Inhalt der Datei webflow-footer-code.html in den Footer Code einfügen. Die Library steckt darin vollständig, das Projekt ist damit von keinem fremden Server abhängig.

Projekt-Defaults (optional)

Setzt den Hausstil eines Projekts. Muss im Footer Code über dem Library-Code stehen. Alles, was du nicht angibst, behält den Standardwert.

<script>
  window.WFAnimConfig = {
    duration: 0.9,          // Sekunden
    ease: 'power3.out',
    start: 'top 85%',       // wann Reveals starten
    distance: '2.5rem',     // Weg bei fade-up & Co.
    stagger: 0.08,
    locale: 'de-DE',        // Zahlenformat für counter
    mobileBreakpoint: 768   // für data-anim-mobile="false"
  };
</script>

Basis-Reveals

Elemente erscheinen, sobald sie in den sichtbaren Bereich scrollen. Standardmäßig einmalig; mit data-anim-repeat auch erneut.

Fade

Einblenden mit Bewegung aus der jeweiligen Richtung. fade-left bewegt sich nach links, kommt also von rechts.

  • fade-in · fade-up · fade-down · fade-left · fade-right
  • data-anim-distance="3rem" Weg (px, rem, vh, vw)
fade-up
fade-left

Scale & Blur

Leicht aus kleiner Größe oder aus der Unschärfe. Wirkt ruhiger als ein Fade mit Weg.

  • data-anim-scale="0.85" Startgröße (Standard 0.92)
  • data-anim="blur-in" · data-anim-blur="20" in px
scale-in
blur-in

Clip

Aufdecken über eine Maske. Ideal für Bilder und farbige Flächen. Die Richtung gibt an, wohin sich die Kante bewegt.

  • clip-up · clip-down · clip-left · clip-right
2

Gruppen & Listen

Das Attribut kommt an den Container, die Kinder erscheinen nacheinander. Bei Collection Lists das Attribut an die Collection List setzen, nicht an den Wrapper.

Stagger

Direkte Kinder erscheinen versetzt. Liegen die Elemente tiefer verschachtelt, markiere sie mit data-anim-item.

  • data-anim-stagger="0.12" Abstand in s
  • data-anim-stagger-type="scale-in" jeder Reveal-Typ

Grid-Stagger

Breitet sich im Raster aus, standardmäßig von der Mitte. Gut für Logo-Wände und Galerien.

  • data-anim-from="start" · center · end · edges · random
  • data-anim-stagger-type wie bei stagger
3

Text

Basiert auf GSAP SplitText. Zeilen werden nach Resize und Font-Laden automatisch neu berechnet. Für Screenreader bleibt der Text lesbar.

Split Lines

Zeilen gleiten nacheinander aus einer Maske. Der Klassiker für Headlines.

  • auch split-words (Wort für Wort)

Gute Animation fällt nicht auf. Sie lenkt den Blick dorthin, wo er hin soll.

Split Chars

Buchstabe für Buchstabe. Am besten für kurze Headlines bis etwa vier Wörter.

Hallo Bremen

Scramble

Der Text entschlüsselt sich. Nur für reinen Text ohne verschachtelte Formatierung.

  • data-anim-chars="01" eigene Zeichen, oder upperCase, lowerCase

Highlight

Ein Marker oder eine Unterstreichung zeichnet sich ein. Ans Inline-Element (Span) im Text hängen.

  • data-anim-style="underline" · data-anim-thickness="0.15em"
  • data-anim-color="#ffd400" oder CSS-Variable --anim-highlight

Wir bauen Websites, die schnell laden und sich gut anfühlen.

4

Scroll-gebunden

Diese Animationen folgen direkt der Scrollposition und laufen beim Hochscrollen rückwärts.

Bild-Parallax

An den Image-Wrapper (festes Seitenverhältnis). Das Bild darin ist höher als der Wrapper; die Library misst den Überstand und bewegt das Bild genau um diesen Wert.

  • Bild in Webflow: width 100% · height 110% · object-fit: cover
  • data-anim-amount="15" setzt die Bildhöhe auf 115 %
  • data-anim-direction="up" Richtung umkehren

Element-Parallax

Ein beliebiges Element bewegt sich langsamer oder schneller als die Seite. Negative Werte machen es schneller.

  • data-anim-speed="0.3" (Standard 0.2)
0.25
−0.15

Image Zoom

Das Bild im Wrapper zoomt beim Scrollen langsam heraus.

  • data-anim-scale="1.3" Startzoom (Standard 1.2)

Text Fill

Der Text färbt sich Wort für Wort ein, während du scrollst. Für große Statements.

  • data-anim-opacity="0.2" Startdeckkraft
  • data-anim-start / data-anim-end Scrollbereich

Wir glauben, dass jede Bewegung auf einer Website einen Grund braucht. Alles andere ist Lärm.

Progress Bar

Zeigt den Scrollfortschritt. Die Leiste oben auf dieser Seite ist eine. Styling (fixed, Höhe, Farbe) machst du in Webflow.

  • data-anim-trigger="#artikel" nur Fortschritt eines Bereichs

Pin

Die Section bleibt stehen, während die mit data-anim-item markierten Kinder nacheinander erscheinen.

  • data-anim-length="200" Dauer in % der Fensterhöhe
  • data-anim-item-type="fade-left" Effekt der Items

Funktionale Effekte

Kleine Bausteine für Zahlen, Logos, SVGs und Hover.

Infrastruktur

Was die Library im Hintergrund erledigt, und wie du sie bei Bedarf steuerst.

  • Bewegung reduzieren: Ist die Systemeinstellung aktiv, werden Inhalte ohne Animation angezeigt. Ausnahmen sind Progress Bar und Horizontal Scroll, weil sie für die Bedienung gebraucht werden.
  • Fehlertoleranz: Fehlt ein Plugin oder ist ein Wert unbekannt, erscheint eine Warnung in der Konsole und das Element wird normal angezeigt.
  • Nicht mischen: Kein data-anim auf Elementen, die zusätzlich eine native Webflow Interaction haben. Beide setzen transform und überschreiben sich.
  • Lazy Loading: Die Library rechnet nach dem Laden der Schriften neu. Verändert sich das Layout später (Tabs, Akkordeons), rufe WFAnim.refresh() auf.
WFAnim.init(element)   // neue Elemente animieren, z. B. nach CMS Load More
WFAnim.refresh()       // Positionen neu berechnen
WFAnim.destroy()       // alles zurücksetzen
WFAnim.register('mein-effekt', (el, opts) => {
  gsap.from(el, { rotate: -8, autoAlpha: 0, scrollTrigger: { trigger: el, start: opts.start } });
});
